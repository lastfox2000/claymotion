# 小企鹅学煎饼 · production log

## 1. 导演方案

**Logline**：一只小黏土企鹅想抛出一张完美的煎饼；煎饼没接住，扣在他头上，最后却顺着头顶滑下来，正好落进他手里的平底锅。

**Style**：clay（黏土定格），20 秒，1920×1080，24 fps，无旁白，有配乐和拟音。

**故事骨架（20 s，一个 gag）**
- **Setup 0–7 s**：小企鹅盯上灶台边的小木凳，爬上去，拍手，拿起平底锅，锅里有一张煎饼。他要抛一次。
- **Surprise 7–12.5 s**：下蹲、抡锅、抛起；煎饼飞得太高，他仰头去接，煎饼啪地扣在他头上。
- **Reaction / payoff 12.5–17.5 s**：他愣住、眨眼；煎饼从头顶往前滑，掉下来；他下意识把锅一伸，煎饼正好落进锅里。
- **Button 17.5–20 s**：近景：惊讶 → 泄气 → 闭眼深呼吸 → 得意地笑。

## 2. 实际制作记录（2026-11-22）

- 实际使用 `sheet_catch2.png`（单张煎饼版）和 `close_face2.png`（裁成头肩近景）；`sheet_catch.png`、`close_face.png` 是废稿。
- 背景：千问在每张桌面布景里都会自己加一个吉祥物；用千问 edit 把大角色去掉，留下 `bg_wide_clean.png`。桌面中央剩下一颗小番茄，作为道具保留；`bg_mid`/`bg_close`/`bg_smile` 是从这张图裁出的三个视角，避免再次生成角色。
- 动作表和近景带参考图时，千问只给白底 RGBA（alpha 全 255）。流程是：`slice --birefnet` → `cut.py` 出每个 cell 的 mask → mask 腐蚀 1px + 0.7px 模糊后写回 alpha，去掉白边。
- 近景 2×2 出的是全身；用 PIL 按 alpha bbox 裁到头肩，再重算 anchors。
- 成片 4 个镜头：7.0 / 5.5 / 5.0 / 2.5 秒，240 drawings，1920×1080，24 fps。
- 声音：`-14.4 LUFS`，true peak `-1.4 dBTP`，20.0 秒；`sound.py check` 通过。
- 自检：`selfcheck.py` 无 too dark；`liveness` 无警告；长 hold 已拆开（climb_7 中途回 climb_6 一次，toss_7 中途回 toss_6 一次）。
