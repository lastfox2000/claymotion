# Changelog

## 1.0.0 — 2026-11-22

- First packaged release of **claymotion**, an Agent Skill for one-line stop-motion shorts.
- Bundles lemo-animi 0.1.x scripts, 8 material styles, references and the 20 s `pancake` worked example.
- Adds a cross-platform `claymotion.py` CLI, `setup.py`, and three image backends:
  - ComfyUI + Qwen-Image 2.1 (`comfy_qwen.py`)
  - OpenAI-compatible Images API (`openai_images.py`)
  - MiniMax H3-Image (`h3_image.py`)
- Adds platform notes for Doubao, Grok Bot, Kimi, Codex and Claude Code.
- Adds a Source Han Sans common-character subset (OFL) and a 512×512 icon.
- Fits Doubao limits: ZIP ~2.0 MB, 187 entries, max file 0.79 MB.
